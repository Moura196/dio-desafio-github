Principais Estruturas de Dados e seus Métodos:
- Primitivos:
	Números(sem aspas), String, Boolean, Null, Undefined

- Não primitivo:
	Objetos, Arrays

- Métodos Strings(algun:
	Concatenação
	Propriedade Length
	Iterabilidade
	Formatação
	Index de letras

- Métodos Números:
	Operações Aritméticas

- Métodos Boolean(validar condicionais):
	Validação/Comparação

- Métodos Arrays:
	Array = Lista iterável de elementos
	Push -> Adicionar no final da lista
	Pop -> Retira o ultimo elemento
	Shift -> Retira o primeiro elemento
	Unshift -> Adiciona no início da lista

- Métodos Objetos(semelhante a dicionário):
	Estrutura:
	let person = {
		keys---values
		name: 'John'
		age: 20
	};

- Empty, null e undefined:
	Empty: variável/objeto/array declarada ou inicializada com nenhum valor
	Null: não inicializado, valor não existe
	Undefined: não declarado e vazio
