# ESTRUTURA DO PROJETO
- Contexto e Objetivos: 
    - Assunto de interesse: Assuntos do curso de preparação para o exame de certificação Github Foundations.
    - Objetivos de estudo: É ter materiais de estudos de formatos variados para facilitar o meu processo de aprendizado e assimilação do conteúdo que irá cair na prova. Foi pensado o peso que cada disciplina tem no exame.

- Curadoria de Fontes: Para facilitar a visualização das fontes que anexei no NotebookLM, irei colocar aqui o link do NotebookLM criado. Deixarei público para pode ajudar outras pessoas que estejam se preparando para a prova. [NotebookLM para preparação do exame do Github Foundations](https://notebooklm.google.com/notebook/c3e7c37d-07b6-448e-9699-5933a61646f1).

- Engenharia de Prompts e "Cicatrizes": Além das perguntas presentes no NotebookLM de estudo, pedido de explicações apartir dos cards criados, também criei uma conversa com a IA do Gemini para me ajudar a criar uma descrição de um agente que me ajude a criar documentos de diversas fontes dentro do NotebookLM que estejam de acordo com as minhas necessidades, que neste caso específico é a preparação para o exame do Github Foundations. O agente criado tem a função de estrutura exatamente o que eu preciso estudar, considerando seu grau de importante/cobrança no exame, me permitindo ter uma maior eficiencia no exame. Segue o link da conversa com o [Gemini](https://gemini.google.com/share/fb30d3b1fb45).
